# Deadline — Bible de jeu v0.1

**Titre dans le dépôt : Deadline / DeadLine. Titre de travail utilisé dans les échanges : Signal Mort.** La graphie publique reste à valider.

Jeu solo d’action et d’infiltration cyberpunk pour adultes, en ville libre, avec une caméra 2.5D en vue haute. Le prototype vise le navigateur desktop avec Three.js, TypeScript et Rapier. Le joueur est un coursier menacé de révocation civile. Il se déplace à pied ou en voiture et équipe deux implants pour adapter son approche.

## État des décisions

Les acquis du projet sont la ville libre, la campagne solo, les implants, le ton adulte, les trois quartiers inspirés d’Angoulême et le prototype « Puce fantôme ». Les personnages supplémentaires, le nom de l’entreprise, les quêtes et les fins constituent des propositions v0.1. Les durées et récompenses servent au premier équilibrage.

Le **prototype jouable** comprend l’îlot gare–L’Houmeau, M01 « Puce fantôme » et U01 « Une porte de plus ». Les autres fiches servent à concevoir la campagne. Les identifiants M, U et C désignent respectivement les missions principales, les quêtes uniques et les modèles de contrats communs.
